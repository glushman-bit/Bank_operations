## Приложение для анализа банковских операций

### Установка
Скопировать репозиторий на ПК: git clone https://github.com/glushman-bit/Kursovaya_1.git 

В проекте используется Poetry, для установки виртуального окружения и всех зависимостей необходимо использовать команды: poetry install, poetry sync
стереть .example у шаблона .env.example, внести необходимые для работы API-ключи.

### Использование
Выполнить установку, разместить файл который необходимо обрабатывать в паку data в корневой директории. Настройки пользователя хранятся в файле user_settings.json в папке корневой директории приложения.

### Содержание проекта
Проект содержит модули:

views.py - содержит функции для формирования функции главной вэб-страницы;
utils.py - содержит функции для получения данных из файлов;
services.py - содержит функции сервисы для обработки данных с транзакциями;
decorators.py - содержит функцию декоратор для отчётов;
reports.py - содержит функцию создания отчёта;
config.py - содержит пути для работы с файлами и записи логов;
main.py - основной модуль для запуска проекта.

### Тесты
Репозиторий содержит тесты. Используется фреймворк PyTest. Тестами покрыты все функции (покрытие примерно 80+%). Для запуска тестов с автоматическим формированием результатов необходимо выполнить команду: pytest --cov=src --cov-report=html

### Логирование
Логирование ведётся для каждого модуля. Запись логов ведется в корневую папку logs.
